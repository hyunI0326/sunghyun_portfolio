# Sunghyun Kim — Portfolio

A single-page personal portfolio based on Sunghyun Kim's public GitHub profile and CV.

## Preview locally

No build step is required.

```bash
cd sunghyun-portfolio
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Files

- `index.html` — content and structure
- `styles.css` — responsive visual system and animations
- `script.js` — reveal animation, typing effect, cursor glow, and live GitHub repository cards

## Deploy

This is a static site, so it can be deployed directly to GitHub Pages, Vercel, Cloudflare Pages, or Netlify.
